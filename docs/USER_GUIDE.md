# CRRC_PM 系统使用说明

## 1. 登录与基础操作

系统登录后，会根据当前账号绑定的角色自动展示可访问页面。一个用户可以同时拥有多个角色，系统权限按角色并集计算。

常用入口：

- 右上角“修改密码”：登录后可修改当前账号密码。
- 右上角消息铃铛：显示当前用户待办、审核通知、确认通知。管理员 admin 不显示消息提醒。
- 顶部搜索框：可搜索项目、版本、SN/MAC，并跳转到对应页面。

## 2. 角色权限说明

### 系统管理员 admin

admin 用于系统维护和数据管理。

可操作内容：

- 可查看所有页面。
- 可使用所有功能按钮。
- 可新增用户、分配角色。
- 可删除所有业务数据。
- 不显示消息提醒。

注意：admin 是维护账号，不建议作为日常业务账号使用。

### 领导

领导负责审核和查看全局数据。

可操作内容：

- 查看所有业务模块。
- 审核项目立项、需求书、需求变更、测试用例、硬件测试、故障分析、发货批次等需要审核的事项。
- 查看项目看板、统计报表、项目进度、版本矩阵、问题统计。
- 审核通过或驳回后，提交人会收到消息提醒。

限制：

- 客供资料删除不对领导开放，仅项目助理和 admin 可删除。
- 板卡出厂测试审核由质量检查人员负责。

### 项目助理

项目助理负责项目资料、需求资料、测试资料和问题闭环管理。

可操作内容：

- 项目立项：新增、修改、提交审核、查看、上传立项书。
- 项目立项审核通过后，仍可在项目详情中上传/替换立项书。
- 需求书管理：上传、提交审核、查看、下载。
- 需求变更：上传、提交审核、关闭需求变更。
- 客供资料：上传、查看、下载、删除。
- 软件管理：可新增项目分支，项目分支的软件负责人自动绑定项目立项的软件负责人。
- 硬件版本、硬件测试、软件版本、项目分支：可查看、下载。
- 测试管理：测试用例、问题闭环除审核外可操作。
- 问题闭环：可新增、修改、导出问题记录。
- 售后管理：仅查看。
- 统计报表：正常查看。

限制：

- 不可审核。
- 需求变更只有项目助理可以关闭。

### 软件负责人

软件负责人负责软件版本、软件分支和研发问题处理。

可操作内容：

- 查看项目立项管理。
- 查看、下载需求书、需求变更、客供资料。
- 软件版本：全部权限开放。
- 软件分支：全部权限开放。
- 测试用例：查看、下载用例、下载报告。
- 问题闭环：查看、回复、导出问题记录。
- 收到问题闭环问题后，需要在消息中点击“确认”，项目助理会收到确认通知。
- 收到需求变更通知后，需要在消息中确认已收到，上传人会收到确认通知。
- 查看统计报表。

限制：

- 不可新增项目。
- 不可上传需求书、需求变更、客供资料。
- 不显示生产管理、发货管理、售后管理。
- 回复问题只能由当前问题负责人操作。

### 硬件负责人

硬件负责人负责硬件版本、硬件测试、生产测试大纲。

可操作内容：

- 查看项目立项管理。
- 查看、下载需求书、需求变更、客供资料。
- 硬件版本：全部权限开放。
- 硬件测试：除审核外全部权限开放。
- 生产测试大纲：上传、更新、查看所有历史文件。
- 测试用例：查看、下载用例、下载报告。
- 问题闭环：查看、回复、导出问题记录。
- 收到问题闭环问题后，需要在消息中点击“确认”，项目助理会收到确认通知。
- 查看统计报表。

限制：

- 不可审核。
- 不显示生产烧录、发货管理、售后管理。
- 回复问题只能由当前问题负责人操作。

### 生产人员

生产人员负责烧录、出厂测试前置处理、库存相关生产流程。

可操作内容：

- 查看项目看板。
- 查看项目立项管理。
- 生产管理除审核外全部权限开放。
- 生产烧录：上传、查看、删除批次。
- 删除生产烧录批次时，会同步删除对应出厂测试和库存中的 MAC/SN 信息。
- 生产测试大纲：只能查看最新文件。
- 生产人员会在项目看板待办中看到发货人员提交的生产请求。
- 如果库存中对应产品型号数量不足，该生产请求会持续显示在生产人员待办中。
- 点击消息中的“确认”后，发货人员会收到确认通知。
- 查看统计报表。

限制：

- 不可审核。
- 不显示需求管理、硬件管理、软件管理、测试管理、发货管理、售后管理。

### 质量检查人员

质量检查人员负责生产管理中的出厂测试审核。

可操作内容：

- 查看项目看板。
- 查看项目立项管理。
- 审核板卡出厂测试。
- 同一产品型号只需审核一次，不需要按每个 MAC 单独审核。
- 查看统计报表。

限制：

- 只负责生产测试审核，不负责其他模块审核。

### 发货人员

发货人员负责库存选择、发货批次、出库流程。

可操作内容：

- 查看项目看板。
- 查看项目立项管理。
- 发货管理除审核外全部权限开放。
- 新增发货批次。
- 新增发货批次时必须上传发货单文件。
- 新增发货批次时从库存中选择设备，只展示终端类型、终端型号、SN、MAC。
- 库存不足时，可在新增发货批次弹窗中点击“生产请求”，填写生产需求并发送给生产人员。
- 发货批次审核通过后，设备进入出库记录。
- 生产人员确认生产请求后，发货人员会收到消息提醒。
- 查看统计报表。

限制：

- 不可审核发货批次。

### 发货审核

发货审核角色专门负责发货批次审核。

可操作内容：

- 查看项目看板。
- 查看项目立项管理。
- 查看发货管理。
- 审核发货批次。
- 审核时可以下载发货人员上传的发货单文件。
- 查看统计报表。

限制：

- 不可新增发货批次。
- 不可操作发货批次的新增、修改、删除。

### 售后人员

售后人员负责售后维修和故障分析。

可操作内容：

- 查看项目看板。
- 查看项目立项管理。
- 查看需求管理。
- 查看硬件管理。
- 查看软件管理。
- 查看测试管理。
- 售后管理除审核外全部权限开放。
- 维修记录中的问题默认已闭环，并会进入问题统计。
- 故障分析报告可上传方案文件，方案文件显示上传文件名。
- 查看统计报表。

限制：

- 不可审核。

## 3. 主要业务流程

### 项目立项流程

1. 项目助理新增项目。
2. 新增项目时选择软件负责人，软件负责人来自系统已注册的软件负责人用户。
3. 新项目初始状态为草稿，只有项目助理可见。
4. 项目助理提交审核后，领导可见并审核。
5. 审核通过后，其他有查看权限的用户才能看到该项目。
6. 所有与项目有关的业务模块，只读取审核通过的项目。

### 需求书流程

1. 项目助理上传需求书。
2. 需求书名称自动取上传文件名，无需手动填写。
3. 上传后先是草稿，仅上传人可见。
4. 提交审核后，审核人员可见。
5. 审核通过后，有查看权限的用户可查看/下载。

### 需求变更流程

1. 项目助理上传需求变更。
2. 需求变更名称自动取上传文件名。
3. 上传后草稿仅上传人可见。
4. 提交审核后，审核人员可见并可下载文件查看。
5. 审核通过后，系统通知对应项目的软件负责人。
6. 软件负责人在消息中确认已收到。
7. 上传人收到“软件负责人已收到”的消息提醒。
8. 需求变更关闭仅项目助理可操作。

### 问题闭环流程

1. 项目助理新增问题。
2. 问题来源默认为研发，不再手动选择。
3. 问题负责人自动绑定项目的软件负责人。
4. 当前问题负责人可回复问题。
5. 其他人即使能查看，也不能回复非自己负责的问题。
6. 软件负责人/硬件负责人收到问题后，需要在消息提醒中确认。
7. 项目助理收到确认通知。
8. 重新打开的问题会计入次数，重新打开超过两次计入严重问题统计。

### 生产测试大纲流程

1. 硬件负责人进入生产管理 - 生产测试大纲。
2. 选择硬件版本中的产品型号。
3. 填写对应板卡型号，多个型号用逗号分隔。
4. 上传测试大纲文件。
5. 硬件负责人可查看所有历史文件。
6. 生产人员只看到最新版本文件。
7. 板卡型号可在列表中展开查看完整型号。

### 生产烧录与出厂测试流程

1. 生产人员上传生产烧录数据。
2. Excel 中如果 SN 或 MAC 重复，只录入第一条。
3. 烧录后，生产人员待办中会出现该批次待测试提醒。
4. 出厂测试通过后，对应 MAC 进入库存。
5. 质量检查人员审核板卡出厂测试。
6. 同一产品型号审核一次即可，不需要逐个 MAC 审核。
7. 删除生产烧录批次时，相关出厂测试和库存数据同步删除。

### 发货批次与出库流程

1. 发货人员新增发货批次。
2. 必须上传发货单文件。
3. 从库存中选择要发货的设备。
4. 库存设备选择列表只显示终端类型、终端型号、SN、MAC。
5. 保存批次后提交审核。
6. 发货审核或领导审核发货批次。
7. 审核人员可以下载发货单文件。
8. 审核通过后，设备从库存进入出库记录。
9. 如果库存不足，发货人员可发送生产请求给生产人员。
10. 生产人员确认后，发货人员收到通知。

### 售后流程

1. 项目关闭后转入售后范围。
2. 售后模块里的项目均来自项目立项中已关闭的项目。
3. 售后人员新增维修记录。
4. 维修记录的问题默认已闭环，并进入问题统计。
5. 故障分析可上传方案文件，文件名取上传文件名称。

## 4. 统计报表与项目看板

项目看板：

- 进行中项目：读取项目立项中审核通过且进行中的项目。
- 待处理问题：读取当前用户负责的未闭环问题。
- 本月发布版本：读取本月已发布的软件版本数量。
- 待办事项：按当前用户角色展示待审核、待回复、待测试、生产请求等事项。

统计报表：

- 项目进度：读取项目立项阶段和进度。
- 版本矩阵：只读取已发布的软件版本。
- 问题统计：来自测试管理的问题闭环和售后维修记录。
- 维修记录的问题默认已闭环。

## 5. 文件上传与下载

系统支持多个模块上传文件，包括：

- 项目立项书
- 需求书
- 需求变更
- 客供资料
- 硬件版本压缩包
- 硬件测试资料
- 测试用例/测试报告
- 生产测试大纲
- 发货单文件
- 故障分析方案文件

上传后的文件可在对应详情或审核页面下载。部分模块保留本地预览能力。

## 6. 注意事项

- 草稿状态的数据通常只有上传人或创建人可见。
- 提交审核后，审核人员才能看到。
- 审核通过后，有查看权限的角色才能看到。
- admin 是系统维护账号，不显示消息提醒。
- 删除操作会影响业务数据，请谨慎操作。
- 已审核通过的业务数据通常不建议删除，但 admin 具备维护级删除能力。
